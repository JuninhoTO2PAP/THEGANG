# Frontend — THE GANG

PWA em HTML/CSS/JS (Vite). Nesta entrega: login, cadastro **só com convite** e Configurações com painel de convites para o admin.

## Rodar

Com a API em `http://127.0.0.1:8000`:

```powershell
cd frontend
npm install
npm run dev
```

Abra http://localhost:5173
